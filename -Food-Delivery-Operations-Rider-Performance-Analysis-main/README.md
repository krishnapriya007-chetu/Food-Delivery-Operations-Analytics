# Food Delivery Operations & Rider Performance Analytics

## Project Overview
An end-to-end analytics project analyzing 42K+ food delivery transactions across 9,600+ delivery zones to identify operational bottlenecks, investigate delivery delays, and evaluate rider performance across 1,300+ riders.

## Objectives
- Analyze delivery performance and identify operational bottlenecks.
- Investigate the impact of traffic, weather, and festival conditions on delivery delays.
- Evaluate rider performance using a composite scoring model.
- Identify factors contributing to SLA breaches and delivery inefficiencies.

## Tools & Technologies
- **Python:** Data cleaning, exploratory data analysis and statistical analysis.
- **SQL:** Data querying and analysis.
- **Power BI:** Interactive dashboard development.
- **Excel:** Data inspection and preparation.

## Key Analysis Areas
- Delivery time and SLA breach analysis.
- Rider performance evaluation.
- Traffic, weather and festival impact analysis.
- Statistical testing to investigate delivery performance differences.
- Delay risk analysis and operational recommendations.
